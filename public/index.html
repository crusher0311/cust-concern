Customer Concern Assistant — OpenAI Proxy

The proxy is available at /api/openai. Set OPENAI_API_KEY and (optionally) PROXY_SECRET in your Vercel environment variables.

After deployment, point the extension options "OpenAI Proxy URL" to this site (for example https://cust-concern.vercel.app) and set the Proxy Secret in the extension to match the PROXY_SECRET env var.
