Instructions

1. Enter the customer's concern in the input box and click "Submit Concern".
2. Follow-up questions will be listed in the Follow-Up List section. Click on a question to move it to the active area.
3. Enter the customer's response to each follow-up question and click "Submit".
4. Use the "Save" button to save the conversation when complete.

OpenAI API Key

Enter your OpenAI API key to enable AI features. The key is stored locally in your browser's extension storage.

OpenAI Proxy URL (optional)

If you deploy the recommended server-side proxy, set its base URL below (for example: https://my-proxy.example.com). If set, the extension will call your proxy instead of directly calling OpenAI.
